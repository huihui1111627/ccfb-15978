# AMSGW — 业余无线电位置汇聚 / 中继与网关模拟服务器

一个无外部依赖的 Go 程序：在进程内模拟固定种子的数百个台站、数十个中继和接入网关、无线信道丢包/重复/延迟/畸形报文，运行位置汇聚、路径改写、听邻网关选择、第三方下行封装、呼号口令、物体代管和时间补全，并提供嵌入式网页地图与逐条报文路径检查。

## 运行

```bash
go run .
# 打开 http://localhost:8088
```

常用参数：

```bash
go run . \
  -addr :8088 \
  -seed 987654321 \
  -stations 300 \
  -relays 24 \
  -gateways 12 \
  -clients 30 \
  -duration 120m
```

启动时会先完成确定性模拟。全量 300 台站规模通常约十几秒；网页右上角“验收对账”会在后台再运行一次独立参照实现。

## 测试与验收

```bash
go test ./...
```

关键一致性测试：

```bash
go test ./internal/reference -run TestParityFixedSeedAcceptance -v
```

该测试使用固定种子生成：

- 300 个会员/移动/固定台站，另有 12 个气象站；
- 24 个中继、12 个接入网关、30 个在线客户端；
- 每一条“发射键 × 接收台站”的稳定伪随机命运：丢包、重复、1–90 秒延迟；
- 42 条随机插入的格式错误或字段错误报文；
- 随机短消息、客户端发送、物体报告、合法/非法撤销和其他服务器联邦报文。

`internal/reference` 是独立编写的参照引擎，不复用 `core.Hub` 的分发和对象管理代码，只共享场景数据与稳定损伤函数。它逐包重放：

1. 通用别名/跳数改写与零跳停止；
2. `qDIR` / `qRLY` / `qNET` 来源标记；
3. 网关最近听邻与下行选择；
4. 第三方报文封装；
5. 客户端订阅/私信集合；
6. 物体 owner 与撤销授权；
7. 畸形报文、拒收和 NAK。

测试逐客户端比较最终报文 ID 集合，并比较台站 RF 收件集合、物体状态、来源类别、路径、下行网关和 RF 送达结果。当前固定种子结果为完全一致。

## 网页功能

- 地图显示台站、气象站、中继、网关和物体/地标；
- 每个台站的报告轨迹按原因着色：
  - 红色大点：转弯立即补报；
  - 蓝点：移动周期报告；
  - 灰点：静止心跳；
  - 绿点：首次/启动报告；
- 点击台站可看速度、方向、报告点数和相邻报告间隔，轨迹疏密直接可见；
- “报文路径”中点击任意报文，可看：
  - 原始帧；
  - 经过的中继呼号；
  - 服务器收到的所有重复副本；
  - `qDIR=...`、`qRLY=...`、`qNET=...` 来源途径；
  - 短消息选中后在地图上画来源 → 中继 → 网关 → 收件人的路径；
  - 下行第三方封装帧和负责发送的网关；
- “物体代管”显示物体的原报告 owner 和最后代报告者；只有 owner 且口令正确时可撤销；
- “短消息”可用顶部登录呼号发送；输入框支持最近听到呼号的 datalist；
- “客户端”列出每个模拟客户端的口令状态、订阅条件和最终收件 ID 集合；
- “验收对账”展示网页进程内参照引擎的实时对账结果。

## 呼号口令

口令是由呼号主名计算的 15 bit 哈希（APRS passcode 风格）：

```text
hash = 0x73e2
对主呼号（忽略数字 SSID）奇偶字节分别左移/直接异或
passcode = hash & 0x7fff
```

网页点“算口令”会在浏览器中执行同一算法。口令错误的模拟客户端 `can_send=false`，但仍按订阅规则收报；HTTP 发送和物体撤销会返回 `403` 并记录 denial。

## 路径协议约定

线路帧类似 TNC2 文本：

```text
SRC>DST,PATH:TYPE;k=v;...
```

通用别名和跳数：

```text
BG0001>APLOC,WIDE#3:LOC;mid=SIM000001;...
```

匹配别名 `WIDE` 的中继 `RPT01` 处理后：

```text
BG0001>APLOC,RPT01[WIDE]*,WIDE#2:LOC;...
```

随后：

```text
...,RPT01[WIDE]*,RPT02[WIDE]*,WIDE#1
...,RPT01[WIDE]*,RPT02[WIDE]*,RPT03[WIDE]*,WIDE#0
```

`WIDE#0` 不再被任何中继转发。同一中继还按 `MID` 去重，防止随机重复和环路。

网关向服务器送帧时追加 q 标记：

- `qDIR=GW01`：网关直接听到来源台站；
- `qRLY=GW02`：经过中继后到达网关；
- `qNET=SRVPEER`：由其他服务器/对等网络转来。

## 第三方下行格式

服务器要求网关转回无线电的私信会包一层：

```text
GW01>APGW:}BG0001>APMSG:MSG;mid=...;to=BG0038;text=...
```

外层来源是网关，`}` 后才是原始来源帧，因此接收方不会把它误认为网关自己发送的消息。

网关只在收件人最近 45 分钟内被该网关**直接**听到时才转发；若多个网关都听到，服务器选择听邻时间最新的网关。

## 时间补全

支持两类紧凑 UTC 时间：

- `DDHHMMz`：日、时、分，例如 `312359z`；
- `HHMMSS`：时、分、秒，例如 `235800`；
- 也接受 `DD/HHMM`、`HH:MM:SS` 等分隔写法。

解析时以服务器接收时间为锚，在相邻日/月候选中选绝对偏差最小的完整时间，因此可跨日、跨月和跨年边界。推断时间与接收时间相差超过 20 分钟时，报文和列表会标红为“时间异常”。

## 代码结构

```text
main.go                     启动参数、嵌入网页、运行模拟和 HTTP
web/                        无外部依赖的 SVG 地图、样式和原生 JS
internal/protocol/          呼号口令、时间补全、帧/路径/q标记/第三方编解码
internal/core/              线程安全汇聚 Hub、去重、订阅、物体授权、状态
internal/sim/               固定种子场景、移动/智能报告、离散事件 RF 模拟
internal/reference/         独立参照引擎与一致性测试
internal/api/               JSON API、登录、发送、撤销、网页验收对账
```
